💌 Thank You Letter
A beautiful, interactive, and mobile-friendly web experience designed to thank someone special for their birthday wishes.

This project takes the user on a delightful little journey through three stages:

The Envelope: A vintage, pulsing envelope that invites the user to click.
The Mini-Game: A cute 4-pair memory matching game to unlock the final message.
The Letter: A beautifully animated handwritten letter on vintage-style paper expressing gratitude.
✨ Features
Interactive UI: Smooth transitions between the envelope, the game, and the letter.
CSS Animations: Floating effects, a glowing wax seal, and elegant text fade-ins.
Vanilla JavaScript Game: A lightweight, built-in memory matching card game.
Responsive Design: Works perfectly on both desktop and mobile devices.
No Build Steps: Pure HTML, CSS (via Tailwind CDN), and JavaScript in a single file.
🛠️ Technologies Used
HTML5: Semantic structure.
Tailwind CSS: (via CDN) For rapid, responsive, and beautiful styling.
Vanilla JavaScript: For the game logic and screen transitions.
Google Fonts: Featuring Dancing Script for the handwriting and Quicksand for the base text.
🚀 How to Run
Because this project is entirely self-contained in a single file, running it is incredibly easy:

Clone this repository or download the thank_you_letter.html file.
Double-click the file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
Enjoy the experience!
🎨 How to Customize
You can easily personalize this project for your own needs by editing the thank_you_letter.html file in any text editor:

Change the Message: Scroll down to <!-- SCREEN 3: THE LETTER --> and replace the text inside the <p> tags with your own message.
Change the Signature: Update the final <p> tag that currently says "Princess" to your own name.
Change the Game Emojis: Locate the JavaScript section at the bottom and find the const emojis = ['🌸', '🌸', '🎀', '🎀', '🎂', '🎂', '💌', '💌']; array. Swap these emojis out for anything you like! Just make sure there are exactly 4 pairs (8 items total).
